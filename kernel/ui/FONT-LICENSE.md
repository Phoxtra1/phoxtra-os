# Carlito font attribution and license

Phoxtra OS embeds a compact rasterization of the Carlito Regular typeface for
its freestanding framebuffer text renderer. Carlito is metric-compatible with
Calibri and is used here as a practical, redistributable substitute; it is not
the proprietary Microsoft Calibri font.
